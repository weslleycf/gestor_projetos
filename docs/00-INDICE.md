# Manual do SGP — Sistema de Gestão de Projetos, Portfólio e Capacidades

Este manual foi escrito para **quem usa o sistema no dia a dia**, não para quem o programa. Aqui você encontra o
que cada módulo faz, quem pode acessá-lo, o passo a passo das tarefas, o significado de cada campo e indicador,
as regras de negócio por trás dos cálculos e as limitações de cada recurso.

---

## Como usar este manual

1. Se é seu **primeiro acesso**, comece por [Visão geral e primeiros passos](01-visao-geral-e-primeiros-passos.md).
2. Se você precisa saber **o que pode ver e fazer**, leia [Perfis, permissões e segurança](02-perfis-permissoes-e-seguranca.md).
3. Depois vá direto ao módulo do seu interesse pela tabela abaixo.
4. Se ficou com uma dúvida específica, consulte as [Perguntas frequentes](12-perguntas-frequentes.md) — elas cobrem
   os problemas mais comuns e o que fazer em cada caso.

Cada documento segue sempre a mesma estrutura: para que serve, quem usa, como chegar, conceitos, tarefas passo a
passo, campos, regras de negócio, como ler os indicadores, boas práticas, perguntas frequentes e — igualmente
importante — **o que aquele módulo não faz**.

## Integrações

O SGP conversa com os sistemas que a empresa já usa. Cada integração pode operar em dois modos:

- **Modo real** — a chamada é feita de verdade no sistema externo, com as credenciais configuradas.
- **Modo simulação** — o sistema monta a requisição e registra exatamente o que seria enviado, sem chamar o
  sistema externo. Serve para validar o mapeamento de campos antes de ligar a integração.

O catálogo cobre ERP, CRM, RH, LMS, Jira, Azure DevOps, Teams, Slack, Power BI/Tableau, Google Calendar, Outlook,
GitHub, GitLab, taxonomia ESCO/SFIA e plataformas de certificação. O detalhamento está em
[11 · Administração](11-administracao.md).

## Convenções deste manual

- **Negrito** indica o nome exato de um botão, campo, aba ou item de menu, como aparece na tela.
- Blocos iniciados por **Atenção** destacam armadilhas comuns e efeitos colaterais de uma ação.
- Toda tabela de indicador traz três colunas de leitura: o que mede, como interpretar e a faixa considerada saudável.
- A seção **O que este módulo não faz** existe para evitar expectativa errada: ela lista o que está fora do
  escopo desta versão.

## Suporte

Se você não encontra um módulo no menu, ele provavelmente não está liberado para o seu perfil — consulte
[02 · Perfis, permissões e segurança](02-perfis-permissoes-e-seguranca.md). Para liberar acesso, cadastrar uma
capacidade nova no catálogo ou ajustar uma integração, procure o administrador do SGP ou o PMO.
